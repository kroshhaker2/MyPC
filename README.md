## Система

```bash
nrs # собрать и применить
nrt # применить до перезагрузки
nrb # применить при следующей загрузке
nrg # только собрать
```

## Конфиги рабочего стола

Hyprland, Waybar и Rofi находятся в `dotfiles/` и подключены напрямую. Для большинства правок `nrs` не нужен.

```bash
hyprctl reload                         # перечитать Hyprland
systemctl --user restart waybar        # перезапустить Waybar
rofi -show drun                        # Rofi читает конфиг при запуске
```

## Бинды Hyprland

`Super` — клавиша Windows. Цифра `0` в биндах рабочих столов означает рабочий
стол №10.

### Приложения и сеанс

| Комбинация               | Действие                            |
| ------------------------ | ----------------------------------- |
| `Super + Enter`          | Открыть Kitty                       |
| `Super + Space`          | Открыть меню приложений Rofi        |
| `Super + E`              | Открыть файловый менеджер Nautilus  |
| `Super + B`              | Открыть Zen Browser                 |
| `Super + L`              | Заблокировать экран через Hyprlock  |
| `Super + Escape`         | Открыть меню Wlogout                |
| `Super + Shift + Escape` | Завершить сеанс Hyprland через UWSM |
| `Super + Shift + R`      | Перезагрузить конфигурацию Hyprland |
| `Alt + Shift`            | Переключить раскладку `us` / `ru`   |

### Окна

| Комбинация                | Действие                                   |
| ------------------------- | ------------------------------------------ |
| `Super + Q`               | Закрыть активное окно                      |
| `Super + F`               | Переключить полноэкранный режим            |
| `Super + V`               | Переключить плавающий режим                |
| `Super + P`               | Переключить псевдотайлинг                  |
| `Super + T`               | Изменить направление следующего разделения |
| `Super + Tab`             | Вернуться к предыдущему фокусу             |
| `Alt + Tab`               | Перейти к следующему окну                  |
| `Super + ←/→/↑/↓`         | Переместить фокус в указанном направлении  |
| `Super + Shift + ←/→/↑/↓` | Переместить окно в указанном направлении   |
| `Super + Ctrl + ←/→`      | Изменить ширину окна на 40 пикселей        |
| `Super + Ctrl + ↑/↓`      | Изменить высоту окна на 40 пикселей        |

### Мышь и тачпад

| Комбинация                          | Действие                          |
| ----------------------------------- | --------------------------------- |
| `Super + колёсико вниз/вверх`       | Следующий/предыдущий рабочий стол |
| `Super + ЛКМ`                       | Перетаскивать окно                |
| `Super + ПКМ`                       | Изменять размер окна              |
| `Super + СКМ`                       | Переключить плавающий режим окна  |
| Горизонтальный свайп тремя пальцами | Переключать рабочие столы         |

### Рабочие столы

| Комбинация            | Действие                                             |
| --------------------- | ---------------------------------------------------- |
| `Super + 1…0`         | Перейти на рабочий стол 1…10                         |
| `Super + Shift + 1…0` | Перенести окно на рабочий стол 1…10 и перейти за ним |
| `Super + Ctrl + 1…0`  | Перенести окно на рабочий стол 1…10 без перехода     |

### Выпадающие рабочие столы

| Комбинация                        | Действие                                                     |
| --------------------------------- | ------------------------------------------------------------ |
| `Super + клавиша ~/Ё` (`code:49`) | Показать или скрыть выпадающий терминал                      |
| `Super + O`                       | Показать или скрыть Obsidian                                 |
| `Super + S`                       | Показать или скрыть свободный scratchpad                     |
| `Super + Shift + S`               | Убрать активное окно в scratchpad                            |
| `Super + Ctrl + S`                | Вытащить активное окно из scratchpad на текущий рабочий стол |

| `L`     | Заблокировать экран     |

| `S`     | Выключить компьютер     |

## Цветовая палитра

Общие цвета находятся в `dotfiles/theme/`: GTK-палитра для Waybar и Wlogout,
Rasi-палитра для Rofi и Lua-палитра для Hyprland. Стили остаются рядом с
конфигами приложений.

Имена `background`, `foreground` и `color0`–`color15` совместимы с форматом
Pywal. Позднее Pywal сможет менять палитру, не перезаписывая сами стили.

## Форматирование и проверки

```bash
treefmt                                # форматировать весь репозиторий
prettier --write dotfiles/waybar       # форматировать Waybar
stylua dotfiles/hypr                   # форматировать Hyprland Lua
nixfmt path/to/file.nix                # форматировать один Nix-файл
statix check .                         # проверить Nix-код
deadnix .                              # найти неиспользуемый Nix-код
nix flake check                        # проверить flake
```
